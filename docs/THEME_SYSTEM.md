## 2. 적용 범위 — 테마는 디자인 세트다

배경색만 바꾸는 게 아니다. 다음 토큰을 **하나의 세트**로 관리하고, 테마 변경 시 앱 전체가 함께 바뀐다:

`Background · Surface · Card · Search Bar · Primary · Secondary · Text · Icon · Button ·
Navigation · Selected State · Favorite Area · Badge`

- 구현은 조각의 `theme/palettes.ts` 방식 승계 — **팔레트 객체 하나 추가 = 테마 하나 추가**가 되도록
  토큰 인터페이스를 고정한다. 컴포넌트는 토큰만 참조하고 색상 리터럴을 직접 쓰지 않는다.
- 광고 배너 영역·시스템 상태바 스타일(light/dark content)도 테마 토큰에서 파생한다 —
  다크 계열 테마(02·06·10)에서 상태바가 검은 글자로 남으면 안 된다.

## 3. 선택 UX

```
Settings → Theme

Current: Minimal Light

┌──────────┐ ┌──────────┐
│ Preview  │ │ Preview  │      ← 이름 + 실제 UI 축소 미리보기
│ Minimal  │ │ Dark     │        (홈 화면 미니어처: 검색바·카드·네비)
│ Light    │ │ Modern   │
└──────────┘ └──────────┘
```

- 미리보기는 스크린샷 이미지가 아니라 **토큰으로 그린 미니어처 컴포넌트**로 — 팔레트를 추가하면
  미리보기도 공짜로 따라온다(이미지 10장 유지보수 회피).
- 선택 즉시 적용 + 로컬 저장(재시작 후 유지).

## 4. ~~미결정~~ → 확정 (2026-08-14)

- **기본 테마 = Minimal Light.** **시스템 다크모드 자동 전환은 하지 않는다** — 테마는 사용자 선택
  단일 축이다. 10종 테마와 라이트/다크 자동 전환을 섞으면 "다크모드인데 Warm Beige면?"이 생긴다.
  다크를 원하는 사용자는 다크 계열 테마(02·06·07·10)를 고르면 된다.
- 테마별 배너 광고 배경 처리(광고는 테마를 모른다) — 경계선/여백으로 흡수, Phase 6에서 확인.
